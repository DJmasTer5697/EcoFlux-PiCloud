# EcoFlux PiCloud — Research-Aligned Software Prototype

**Title:** EcoFlux PiCloud: Energy-Aware Task Scheduling for Sustainable Raspberry Pi-Based Distributed Computing

## What this prototype implements

This software prototype is intentionally aligned with the research papers supplied for the project:

1. **Energy-Efficient Hybrid Framework for Green Cloud Computing (2020):** task/power-aware scheduling, utilization thresholds and consolidation ideas.
2. **A Green Cloud-Based Framework for Energy-Efficient Task Scheduling Using Carbon Intensity Data (2025):** carbon-intensity-aware scheduling and renewable-energy context.
3. **TopADDPi (2025):** low-cost Raspberry Pi cluster, distributed workload execution, workload-dependent performance and hardware limitations.
4. **Model-driven Auto-scaling of Green Cloud Computing Infrastructure:** resource-demand modeling, energy model, queue/auto-scaling concepts and QoS-aware trade-offs.
5. **Green Video Transcoding using Kubernetes:** priority/energy-aware scheduling, renewable-energy availability and dynamic workload allocation concepts.
6. **Energy efficiency and low carbon enabler Green IT framework:** green metrics, utilization, energy efficiency and carbon-emission evaluation.
7. **Raspberry Pi ML evaluation:** resource-constrained edge computing and the importance of CPU/RAM/inference-time trade-offs.
8. **G-80 hybrid ESP32–Raspberry Pi:** energy-aware operational states and on-demand compute as an optional future extension.
9. **Cloud-driven IoT solar tracking:** renewable-energy availability as a future integration point.

## Architecture in the prototype

User → Task Queue → Control/Scheduler → Energy + Carbon Context → Node Selection → Virtual Pi Cluster → Result Logging

The scheduler considers:
- workload demand
- node utilization/headroom
- node energy state
- carbon-intensity model
- renewable availability model
- task priority
- deadline

It also contains a lightweight consolidation mechanism that can place an under-used node into a simulated Sleep state, and a wake-up mechanism when demand rises.

## Important academic limitation

The project does **not** contain a physical Raspberry Pi cluster. Therefore:
- energy values are software-model units;
- carbon values are software-model indicators;
- `observed_python_runtime_s` is runtime on the computer running the prototype, not Raspberry Pi runtime;
- do not write “measured Wh” or “measured Raspberry Pi power” in the paper unless you later perform hardware measurements.

Recommended paper wording:

> “A software-based prototype was implemented in Python to model a four-node Raspberry Pi distributed environment. The prototype evaluates workload allocation, modeled energy cost, carbon-aware scheduling behavior, node utilization, consolidation state changes, task completion, and modeled execution time under conventional and EcoFlux scheduling.”

## Suggested paper mapping

### Research gap
Existing work often focuses on either sophisticated cloud-scale energy optimization/carbon-aware scheduling or low-cost Raspberry Pi distributed computing. The proposed EcoFlux PiCloud combines these directions in a lightweight software model suitable for small-scale academic experimentation.

### System implementation
- Control node: scheduler/dashboard
- Energy monitor: modeled node energy state
- Carbon monitor: modeled carbon intensity
- Renewable context: modeled renewable availability
- Scheduler: energy + carbon + utilization + priority + deadline
- Cluster: four virtual Raspberry Pi nodes
- Consolidation: simulated Sleep state for under-used nodes
- Auto-scaling: wake-up of sleeping node under demand
- Logging: CSV task history

### Evaluation metrics
- modeled energy cost
- modeled carbon impact
- modeled execution time
- node utilization
- task completion
- scheduling mode comparison

## Do not fabricate results

The figures generated by this package are **software-model outputs**. They are useful for demonstrating the prototype and the behavior of the scheduling algorithm. They are not evidence of physical Raspberry Pi energy savings.
